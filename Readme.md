SmartSupport AI – Customer Support Bot

AI-powered customer support bot built with Spring Boot, Spring AI, PostgreSQL (pgvector), and Google Vertex AI.
Provides troubleshooting, warranty automation, service center lookup, ticket generation, and more.

🚀 Features

✅ AI-powered FAQ answering (RAG with product manuals & policies)

✅ Warranty checker (auto-detect if replacement/repair is possible)

✅ Service center lookup by city/region

✅ Ticket creation & tracking

✅ Multi-product support: Smartphones, Laptops, TVs, Refrigerators

✅ Feedback analysis with sentiment detection

✅ Proactive suggestions for users (maintenance tips, updates)

🛠 Tech Stack

Java 21, Spring Boot 3

Spring AI (RAG + LLM integration)

Google Vertex AI (embeddings + LLM)

PostgreSQL + pgvector (vector search)
